# King Family Dash

Family dashboard (leave, checklist, sales, budget, documents, scoreboard, kanban, admin) with a royal purple theme.

Data lives in `kf_` tables on the shared Supabase project. Apply [schema.sql](schema.sql), then the fictional case-study rows in [supabase/kingfamily_seed.sql](supabase/kingfamily_seed.sql). Demo password: `kingdemo`. See [SETUP.md](SETUP.md).
